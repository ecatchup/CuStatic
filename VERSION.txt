[2026-08-26] CuStatic-2.1.3
- BUG: 差分出力でアップロードファイル（webroot/files 配下）が書き出されず、
       新規アイキャッチ画像等が静的サイトに反映されない問題を修正。
       差分出力時に files を増分同期する（同一サイズ・更新日時はスキップ。
       設定 `CuStatic.diffSyncFiles` で無効化可能、既定 ON。削除は行わないため
       完全同期は全件出力で行う）

[2026-08-26] CuStatic-2.1.2
- CHG: 内部リンクの静的URL変換（convertHtmlLinks / convertHref）を CuStaticUtil へ抽出し、
       アドオン（CuStaticAddonMailForm 等）が自前生成するページからも再利用可能に（挙動は不変）

[2026-08-24] CuStatic-2.1.1
- BUG: PATH 上の php が別バージョン（OS 標準の古い PHP 等）のサーバで、
       バックグラウンド書き出しが起動できない問題を修正。
       CLI PHP の自動検出を改善（PHP_BINARY → PHP_BINDIR/php → PATH の順で解決し、
       FPM/CGI 等の非 CLI バイナリを除外）
- NEW: 設定 `CuStatic.phpBinary` を追加（setting_customize.php で CLI PHP のパスを明示指定可能）
- CHG: バックグラウンド実行コマンドを cu_static.log に記録し、起動失敗を画面のログ表示から診断可能に

[2026-08-14] CuStatic-2.1.0
- NEW: オプション設定に「公開URL」（静的サイトを配信するURL）を追加。書き出し処理には影響せず、
       アドオン（CuStaticAddonMailForm 等）が許可オリジンの既定値として参照する

[2026-07-13] CuStatic-2.0.0

- NEW: 書き出し画面末尾にアドオン差し込みスロット（BcFormTable->dispatchAfter）を追加
